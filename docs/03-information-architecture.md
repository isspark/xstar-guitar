# 信息架构与交互设计

## 1. 架构原则

- 一级导航围绕用户任务，不直接暴露抽象的四层产品模型。
- 新用户看到清晰的下一步，已有用户能快速打开工具。
- 知识、练习和曲目通过稳定实体关联，而不是复制内容。
- 网络内容和本地内容在界面上清楚区分。
- 手机、平板和折叠屏共享导航状态，由窗口空间决定单栏或多栏。

## 2. 一级导航

建议采用五个顶层目的地：

| 入口 | 主要内容 | 说明 |
|---|---|---|
| 今天 | 下一步、继续学习、短练习、最近曲目 | 默认首页 |
| 学习 | 学习路径、课程、能力地图 | 零基础主路径与后续路线 |
| 练习 | 自由练习、最近练习、专项训练 | 调音可作为练习前准备 |
| 曲谱 | 本地乐库、收藏、导入、在线搜索 | “在线”是次级来源筛选 |
| 工具 | 调音器、节拍器、和弦库、后续工具 | 已有基础用户直达 |

设置从头像/更多入口进入，不占用首版底部导航位置。若可用性测试显示五项拥挤，可将“练习”并入“今天/学习”，首版采用四项导航。

## 4. 关键页面

### 4.1 今天

内容优先级：

1. 当前唯一主要行动，例如“继续第 4 课：Em 和弦”。
2. 上次中断的课程、练习或曲目。
3. 一个 5 至 10 分钟复习建议。
4. 最近使用工具和曲目。

新用户空状态直接解释路线，并提供“开始认识吉他”和“我只想用工具”。不展示空统计图。

### 4.2 调音器

页面状态：

| 状态 | 页面行为 |
|---|---|
| 权限未请求 | 说明本地分析和不录音，用户点击后请求 |
| 权限拒绝 | 提供重试；永久拒绝时引导系统设置；可退出使用其他模块 |
| 初始化 | 简短加载并允许取消 |
| 等待输入 | 提示逐根拨弦、静音其他弦 |
| 输入过弱/过强 | 给出距离和力度建议 |
| 检测中 | 显示当前弦、音名和偏差趋势 |
| 已调准 | 明确文字、稳定视觉与可选震动；自动进入下一弦 |
| 音频被占用 | 说明冲突，允许重试 |

主控件保持单手可达。频率等专业数据可以弱化，偏低/偏高和下一步操作最突出。

### 4.3 节拍器

- 大号 BPM 数字和开始/暂停为主操作。
- 提供减一、加一、滑动/输入和 Tap Tempo。
- 显示小节内拍点与第一拍重音。
- 课程或练习调用时，显示练习目标且限制不必要设置。
- 蓝牙输出时提示可能存在整体延迟。
- 页面关闭后是否继续播放由明确设置决定；MVP 默认离开即停止，练习内嵌场景除外。

### 4.4 和弦列表与详情

列表支持搜索、MVP 常用、收藏和最近查看。详情包括：

- 和弦图与文字按法。
- 逐弦状态和可选示范音。
- 组成音与最小理论说明。
- 常见问题和简化指法。
- “练这个和弦”“练转换”“用到它的曲目”。

### 4.5 课程详情

- 顶部显示本课唯一目标和预计时间。
- 内容按步骤推进，不以一篇长文章呈现。
- 工具步骤直接嵌入或打开 supporting pane。
- 用户离开时保存当前位置。
- 完成页展示结果，只突出一个下一步。

### 4.6 练习会话

- 开始前显示目标、时长、BPM 和降级选项。
- 会话中只展示当前和弦/动作、下一项、拍点和暂停。
- 防止屏幕休眠可由用户控制。
- 返回时确认“保存为未完成”或“放弃本次”。
- 结束后记录实际时长、BPM、自评和问题，不要求填写长表单。

### 4.7 曲谱库与详情

乐库筛选：本地、收藏、正在学习、已完成、在线。卡片必须标明来源类型。

曲谱详情包括：

- 标题、作者/创作者、来源和许可。
- 难度、BPM、调弦、Capo、所需和弦与节奏。
- “你已经会”和“建议先学”。
- 开始分段、打开曲谱、收藏、来源链接。
- 用户导入内容显示文件类型、导入时间和删除入口。

### 4.8 曲谱阅读

- 手机聚焦正文，允许隐藏一级导航。
- 和弦与歌词使用结构化布局，不以空格强行对齐。
- 点击和弦打开详情；返回恢复段落和滚动位置。
- 可启动统一节拍器并调节 BPM。
- 分段模式突出当前段，完成后进入下一段。
- PDF/图片按页阅读，不假装具备结构化和弦能力。

## 5. 关键用户流程

### 5.1 首次学习

```text
启动
  -> 选择“从零开始”
  -> 查看路线与预计投入
  -> 第一课：认识琴弦
  -> 进入调音准备
  -> 权限说明与系统授权
  -> 完成六弦调音
  -> 保存进度
  -> 推荐下一课
```

权限被拒绝时，可以查看参考音说明、标记稍后完成或返回课程，不形成无法离开的页面。

### 5.2 从课程到练习

```text
课程步骤
  -> 查看和弦按法
  -> 开始关联练习
  -> 预备拍
  -> 练习会话
  -> 自评与问题选择
  -> 更新能力证据
  -> 返回课程原步骤
  -> 完成课程
```

### 5.3 从曲目补前置能力

```text
打开曲目
  -> 查看缺少 C 和弦与八分扫弦
  -> 选择 C 和弦练习
  -> 完成或暂存
  -> 返回曲目同一位置
  -> 开始目标段落
```

### 5.4 导入曲谱

```text
曲谱 -> 导入
  -> 系统文件选择器
  -> 格式/大小/安全校验
  -> 去重判断
  -> 复制到应用私有目录
  -> 生成元数据与预览
  -> 用户补充标题等信息
  -> 打开详情
```

导入失败必须给出原因类别：格式不支持、文件损坏、文件过大、空间不足、权限失效或安全校验失败。

### 5.5 在线搜索与收藏

```text
曲谱 -> 在线搜索
  -> 首次说明查询会发送给所选来源
  -> 输入关键词
  -> 聚合已启用的授权来源
  -> 查看来源/许可/能力
  -> 收藏元数据或合法下载
  -> 不允许缓存时打开来源页面
```

收藏元数据不等于已离线下载，界面和数据状态必须区分。

## 6. 自适应布局

| 场景 | Compact | Medium/Expanded |
|---|---|---|
| 一级导航 | 底部导航 | Navigation Rail/永久导航区 |
| 课程 | 列表进入详情 | 列表-详情 Scene |
| 和弦 | 列表进入详情 | 列表-详情 Scene |
| 曲谱库 | 列表进入预览 | 列表-详情 Scene |
| 课程 + 工具 | 全屏切换或底部面板 | 主内容 + supporting pane |
| 曲谱 + 节拍 | 全屏控制层 | 曲谱 + supporting pane |
| 调音器 | 单主表盘 | 表盘 + 调弦/输入诊断面板 |

实现采用 Navigation 3 `SceneStrategy`，不维护两套独立导航。窗口宽度是布局依据，不能通过设备名称判断平板。分离式铰链两侧可分别放列表和详情。

## 7. 导航与状态恢复

- 每个顶层目的地维护独立 back stack。
- 路由仅携带稳定 ID 和小型值，不传实体、大 JSON、Bitmap 或原始 URI。
- 详情页根据 ID 从 Repository 重载，支持进程死亡恢复。
- 重复点击当前顶层项回到该区域根页面。
- 练习未完成时返回需要确认；其他页面遵循系统预测性返回。
- 课程、练习和曲谱保存内容位置与滚动锚点，不保存不可序列化 UI 对象。

## 8. 通用状态

所有数据页面至少设计：加载、内容、空、可重试错误和不可恢复错误。离线不是全局错误：

- 本地内容始终可浏览。
- 在线搜索区域单独显示断网状态。
- 已失效远程收藏保留元数据和来源链接，并标明当前不可访问。
- 内容解析失败不会导致整个乐库不可用。

## 9. 无障碍与新手友好

- TalkBack 顺序与视觉顺序一致。
- 和弦图提供如“第五弦三品，无名指；第四弦二品，中指”的文字描述。
- 调音状态朗读需节流，避免每帧播报；仅在目标弦或稳定状态变化时提示。
- 节拍视觉不得使用高亮度高速闪烁，可选震动。
- 字体放大后曲谱和弦保持结构关系，按钮不使用固定高度裁切文字。
- 术语首次出现可点按解释，但不打断练习。
- 所有核心操作可由键盘完成，支持方向键、Enter 和 Back/Escape。

## 10. 需要原型验证的问题

- 五项一级导航是否过多，是否应将“练习”并入“学习”。
- 首次路径从“认识琴弦”还是“直接调音”开始更容易激活。
- 调音器自动切弦是否会使零基础用户困惑，是否默认手动逐弦模式。
- 和弦图采用竖向琴头还是横向指板更易理解。
- 练习完成采用一次自评还是问题式反馈更自然。
- PDF/图片与结构化曲谱在乐库中的能力差异如何最清楚地表达。
