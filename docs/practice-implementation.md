# Android 练习模块

## 页面与交互

入口为右侧菜单的「练习」。首页采用 `practice-ui-aurora.html` 的调整版：标题、真实最近记录、双列技能分类，不显示推荐练习。配色直接使用与节拍器、和弦库相同的 `ToolPalette`。

分类覆盖需求文档的 16 个能力领域：演奏准备、左手、右手、单和弦、和弦转换、节奏、扫弦、指弹、拍弦、听音、乐理、指板、技巧、综合演奏、创作和演奏管理。全部练习支持搜索、难度筛选、收藏、已完成、练习中、待复习和未开始筛选。分类显示完成进度，详情显示练习证据及自评稳定速度。

页面直接读取 `MaterialTheme` 的语义颜色，随 APP 预设主题与自定义强调色切换；不再依赖共享可变调色板。亮色主题的当前拍使用 `onPrimary`，保证与按钮一致。

新增笔记供错误日志、计划、曲单和创作草稿使用，按练习本地保存。前置练习可直接跳转且不锁定高级内容。音乐应用、自检、困难处理与相关练习均在详情展示。

节拍训练支持选择拍号、细分与每两轮提速 5 BPM 的目标上限。自动提速仅按计划执行，不代表自动评估演奏正确。

详情提供目标、逐步指导、自检条件、困难处理、合成音高或和弦示范，以及调音器、和弦库和部分曲目应用入口。

执行模式：

- 动作自检：逐项核对指导并确认，全部确认后进入结果页。
- 节拍跟练：复用 AudioMetronome，4 拍预备、音频时钟驱动拍点和动作、轮数、暂停、继续、降速、静音、重来。
- 听音题：高低与相同、常见音程、大三与小三和弦；每组 10 题，可重听，答后解析和统计真实答题结果。

结果记录自评和困难标签。提前退出可保存为未完成，练习历史和首页最近练习来自 Room 数据。当前会话草稿保存于本地；重进同一项目可恢复，节拍练习从暂停所在小节的起点重新进入。进入后台暂停音频。

## 内容与数据

- `PracticeCatalog.kt`：稳定 ID 的指导、动作、目标、和弦关联及听音出题模型。
- `PracticeLibraryScreen.kt`：分类、详情、历史、指导会话、节拍会话与听音结果。
- `PracticeData.kt`：Room v2 增加完成状态、练习单位、正确题数、问题标签；提供 v1→v2 的非破坏迁移。
- 收藏和未完成草稿使用 `practice` SharedPreferences，不需要账号和网络。

当前内容覆盖各能力领域的分步练习与音乐应用，知识、编配和创作使用指导自检及笔记。没有实际音符示例的指导项目不显示无关的默认声音。示范音用于音高、和弦与音序对照，不将合成音冒充拍弦、滑音或击勾弦动作录像。

需求中的真人视频/错误示范素材、专门的多声部跟练编辑、可选音频录制、教师标记以及完整能力掌握证据图仍属于未实现能力；所有内容尚需教学人员实际演奏审核，不能把指导目录覆盖视为全部高级课程制作完成。

## 验证

运行 `:app:assembleDebug :app:testDebugUnitTest :app:lintDebug`。

专项单元测试校验内容 ID、分类和和弦引用，以及多组随机种子下听音正确答案与实际 MIDI 音高的一致性。手机上的布局、音频路由、中断恢复和数据库迁移仍需设备验证。
