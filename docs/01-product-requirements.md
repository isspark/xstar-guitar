# XStar Guitar 产品需求文档

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 状态 | 初始基线 |
| 产品阶段 | MVP 规划 |
| 首发平台 | Android |
| 首发市场 | 中文市场 |
| 首批用户 | 完全零基础的民谣吉他学习者 |

## 2. 背景与问题

零基础用户通常同时面对四类障碍：不知道琴是否调准、不理解教材中的术语、不会组织练习、无法把零散技巧应用到完整歌曲。现有方案常分散在调音器、视频课程、节拍器和曲谱网站之间，用户需要自行判断学习顺序，容易在和弦疼痛、转换缓慢和节奏不稳阶段放弃。

XStar Guitar 将常用工具、必要乐理、结构化练习和曲谱应用连接为一条可执行路径。工具是即时入口，练习和真实曲目是留存核心，知识在需要时解释原因。

## 3. 产品愿景

让每位吉他用户都能知道自己当前能做什么、下一步练什么，以及所学内容能在哪首歌中使用。

产品长期覆盖：

- 零基础：调弦、持琴、开放和弦、基础节奏和第一首歌。
- 入门：更多和弦、扫弦、分解、基础指板和曲目积累。
- 进阶：横按、音阶、CAGED、技巧、听力、即兴和复杂节奏。
- 演奏者：分段变速、Setlist、曲谱管理、音色和设备记录。
- 教学者：课程模板、作业、学生进度；不属于 MVP。

长期覆盖不等于首版同时满足所有人。MVP 只验证零基础民谣弹唱闭环，架构与内容模型为后续阶段预留扩展点。

## 4. 产品目标

### 4.1 MVP 目标

- 用户无需账号，在首次打开后 3 次主要点击内开始第一课或调音。
- 用户能独立完成标准调弦。
- 用户理解并掌握 5 至 8 个常用开放和弦。
- 用户能够在节拍器下完成至少一组和弦循环。
- 用户能够把已学和弦与节奏用于一首完整练习曲。
- 所有核心学习能力在无网络时可用。
- 建立可扩展的能力、内容、练习和曲目关联模型。

### 4.2 非目标

- 不在 MVP 建设账号、云同步或社交社区。
- 不提供未经授权的商业歌曲、歌词或曲谱镜像。
- 不承诺通过麦克风准确识别完整和弦或整段演奏。
- 不制作完整 Guitar Pro 编辑器。
- 不做实时效果器、音箱模拟或专业 DAW。
- 不同时建设民谣、电吉他和古典三条完整课程。
- 不以排行榜、强制连续打卡制造学习压力。

## 5. 用户画像与任务

### 5.1 核心画像：第一次学吉他的用户

- 不了解琴弦、品位、和弦、节拍等术语。
- 可能拥有一把民谣吉他，但没有老师或只看零散视频。
- 每次可投入 10 至 30 分钟。
- 不知道练习是否有效，容易因疼痛、杂音和转换慢而受挫。
- 希望尽快弹出一首可辨认的歌曲，而不是先学完整乐理。

核心 JTBD：

> 当我刚拿到吉他时，我希望有人按正确顺序告诉我当下只需做什么，并能让我确认自己完成了，以便尽快弹出第一首歌。

### 5.2 次级画像：已有基础但需要工具的用户

MVP 不为其建设完整路径，但调音器、节拍器、和弦库、曲谱导入与收藏应可直接使用，不强迫完成新手引导。

核心 JTBD：

> 当我练琴时，我希望快速打开可靠工具或自己的曲谱，而不必经过课程和登录流程。

## 6. 设计原则

- 一屏一主要行动：零基础页面避免同时给出过多选择。
- 先弹后解释：乐理只讲完成当前任务所需的最小概念。
- 知识必须落到练习，练习必须能落到曲目。
- 不确定时不给错误肯定：音频置信度不足应提示重新拨弦，而非误报调准。
- 离线不降级核心价值：网络只增强资源发现。
- 工具直接可用：已有经验用户可跳过引导。
- 隐私可理解：麦克风用途在请求权限前以普通语言解释。
- 状态不只依赖颜色：音准、节拍和完成状态均提供文字或形状反馈。

## 8. 核心业务规则

### 8.1 进度状态

内容状态统一为 `未开始`、`进行中`、`已完成`。重做不会清除历史；跳过不等同于掌握。课程完成可以依赖用户确认和指定练习完成，但 MVP 不伪装成自动演奏评分。

### 8.2 推荐规则

MVP 使用透明规则而非机器学习：

1. 优先恢复未完成会话。
2. 其次推荐新手路径中的下一项。
3. 存在到期复习项时，在首页提供一个短练习入口。
4. 用户打开超出能力范围的曲目时，显示前置内容，但允许继续浏览。

### 8.3 内容关联

- 一个知识点可以关联多个练习和曲目。
- 一个练习必须标记训练的能力。
- 一个曲目必须标记所需能力、和弦、节奏和难度。
- 所有跨页面跳转携带稳定 ID 和返回上下文。

## 9. 非功能需求

### 9.1 离线与可靠性

- 调音、节拍、内置和弦、已安装课程、练习记录、导入曲谱和本地搜索完全离线。
- 进程死亡、强制停止和正常升级后，已提交的进度与设置不丢失。
- 在线资源失效不影响本地内容和已合法下载内容。

### 9.2 性能

- 主流中端机冷启动 TTID 目标：P50 不超过 1.5 秒，P95 不超过 2.5 秒。
- 调音稳定输入至可读反馈目标：P95 不超过 250ms。
- 调音 DSP P95 处理耗时小于一个 hop 周期的 50%。
- 节拍器 40 至 200 BPM 连续运行 10 分钟无累计漂移。
- 音频热路径不持续分配对象，不访问数据库和网络。
- 曲谱按需解码，内存不随完整文件页数线性增长。

### 9.3 适配与无障碍

- 支持手机、平板、折叠屏和可调整窗口。
- 手机采用底部导航；较宽窗口使用 Navigation Rail 和列表详情布局。
- 分离式铰链不得遮挡关键控件或曲谱正文。
- 核心流程支持 TalkBack、外接键盘、字体放大和深色模式。
- 主要触控目标至少 48dp。
- 调音和节拍状态同时提供视觉、文字及可选触觉表达。

### 9.4 隐私与安全

- 麦克风按功能场景请求，原始 PCM 默认不落盘、不上传、不进日志。
- 不申请广泛存储权限，文件导入使用 Storage Access Framework。
- 网络只使用 HTTPS，发布版本禁止明文流量和敏感正文日志。
- 导入内容必须防御 MIME 欺骗、XXE、Zip Slip、Zip Bomb 和超大图片。
- 非必要 Android 组件不得导出。

## 10. 成功指标

MVP 无账号，因此指标采集必须匿名、最小化且取得用户同意；未接入分析 SDK 时可通过内测访谈和本地诊断收集。

| 维度 | 目标 |
|---|---|
| 激活 | 至少 60% 首次用户进入第一课或第一次调音 |
| 首日行为 | 至少 40% 激活用户完成调音或一项结构化练习 |
| 闭环 | 至少 30% 激活用户完成一次“工具-知识-练习-曲目”闭环 |
| 学习成果 | 完成新手路径者能在目标 BPM 完成基础和弦循环及一首练习曲 |
| 易用性 | 5 名零基础可用性测试者中至少 4 名无需提示即可开始首次练习 |
| 稳定性 | 无崩溃用户比例不低于 99.5%，无 ANR 用户比例不低于 99.8% |
| 内容质量 | 上线内容的和弦、节奏、曲谱和授权元数据校验通过率 100% |

## 11. MVP 总体验收

- 全新安装后无需登录即可使用。
- 飞行模式下可以从第一课完成到第一首内置练习曲。
- 用户能成功授予或拒绝麦克风权限，拒绝不会形成死路。
- 标准音样本与代表性真实吉他样本达到调音误差基线。
- 节拍器不使用 UI 定时器作为音频时钟，连续运行无累计漂移。
- 课程、练习、曲谱和能力之间可以双向导航并恢复上下文。
- 导入恶意或损坏文件不会崩溃、不残留临时文件。
- 所有内置和在线资源具有来源和许可记录。
- 手机、平板、折叠屏、字体放大和 TalkBack 核心流程通过验收。

## 12. 待验证假设

- 零基础用户愿意先完成调音再进入第一课。
- 10 至 20 分钟的课程练习组合比长视频更容易完成。
- 5 至 8 个开放和弦足以支撑首批练习曲。
- 用户能够接受 MVP 的自评完成方式，而不要求自动演奏评分。
- 用户本地导入以 PDF 和图片为主；结构化格式的真实需求待调研。
- 合规免费资源是否有稳定 API 与允许的缓存范围，需逐来源评审后决定首发接入范围。
