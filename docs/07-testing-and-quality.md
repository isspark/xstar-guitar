# 测试与质量策略

## 1. 质量目标

- 核心学习流程正确、离线且可恢复。
- 调音反馈可信，置信度不足时不误导用户。
- 节拍声音不累计漂移，UI 卡顿不改变音频时间线。
- 用户文件安全处理，损坏或恶意内容不影响应用稳定性。
- 手机、平板、折叠屏和无障碍用户均可完成核心流程。

| 课程图 | 前置关系、环检测、完成/跳过/重做 |

## 4. 音频专项

### 4.1 调音器

| 维度 | 条件 | MVP 目标 |
|---|---|---|
| 音准 | 标准音与真实吉他 E2 至 E4 | 安静环境稳定后正负 5 cents |
| 噪声 | 风扇、说话、邻弦共振 | 轻噪声正负 10 cents；不稳定时不误报调准 |
| 音量 | 10/30/60cm、强弱拨弦 | 过弱/过强均有正确诊断 |
| 泛音 | 开放弦、十二品泛音、强二次谐波 | 降低八度误判和频繁跳音 |
| 反馈 | 进入/退出阈值 | 视觉稳定，不过度闪烁 |
| 延迟 | 稳定输入到 UI | P95 不超过 250ms |
| 生命周期 | 前后台、旋转、来电、权限撤销 | 正确停止/恢复，无资源泄漏 |
| 路由 | 内置、USB、蓝牙输入 | 不崩溃；不支持场景有明确提示 |

真实录音 fixture 必须由团队录制或确认许可，并记录吉他、弦、拾音距离和环境。

### 4.2 节拍器

| 维度 | 条件 | MVP 目标 |
|---|---|---|
| BPM | 40、60、120、180、200 | 拍间隔符合音频帧计算 |
| 长时 | 10、30、60 分钟 | 不随拍数线性累计漂移 |
| 抖动 | 正常前台负载 | 建立设备基线，目标 P95 不超过 20ms |
| 重音 | 4/4 与预备拍 | 拍序号、第一拍和声音正确 |
| 速度变化 | 下一拍/小节边界 | 无双拍、漏拍或时间线倒退 |
| UI 同步 | 主线程人为卡顿 | UI 可跳帧，声音保持稳定 |
| 路由 | 扬声器、有线、USB、蓝牙 | 切换不崩溃；蓝牙显示延迟提示 |
| 焦点 | 音乐、通知、来电 | 按策略暂停/恢复，不重叠播放 |

节拍 onset jitter 应使用回环录音或外部测量，不以 Compose 动画时间戳代替声音测量。

## 5. 数据与集成

- 首次内容安装可重复执行，不产生重复数据。
- 内容包升级保留稳定 ID 对应的进度。
- Room 每个历史 Schema 到当前版本均通过 Migration Test。
- 强制停止、进程死亡和旋转后恢复合理位置。
- 文件与数据库补偿事务在每个失败点均无孤儿。
- 飞行模式下 P0 内容、工具、练习、导入和本地搜索可用。
- 单个在线 Provider 超时不影响其他 Provider 和本地结果。
- 许可不允许缓存时不能出现下载操作。

## 6. SAF 安全测试

恶意或异常 fixture：

- 扩展名与魔数不一致。
- 截断或畸形 PDF。
- XXE、外部 Schema、深层 XML 和超多节点。
- ZIP 绝对路径、`..` 路径穿越和大量条目。
- 高压缩比 Zip Bomb。
- 超大图片尺寸和解码 OOM 风险。
- 无长度的 `content://` 流。
- 读取中断、用户取消、权限撤销和磁盘空间不足。
- 相同 SHA-256 重复导入。

通过标准：应用不崩溃、不越权读取、不泄露路径、不残留临时文件，并返回用户可理解的错误类别。

## 7. Compose 与导航

- 每个一级目的地独立 back stack。
- 课程、练习和曲谱返回上下文正确。
- 进程死亡后通过稳定 ID 重载，而不是依赖内存对象。
- Compact/Medium/Expanded 均通过。
- 覆盖代表窗口：`400x500`、`400x1000`、`610x500`、`610x1000`、`900x500`、`900x1000`。
- 折叠铰链不遮挡调音表盘、曲谱或主要操作。
- 手机全屏曲谱隐藏导航后，返回行为和系统栏正确。
- 三键、手势和预测性返回均验证。
- edge-to-edge、状态栏、导航栏与 IME 不遮挡内容。

## 8. 无障碍

| 项目 | 标准 |
|---|---|
| TalkBack | 标题、控件、状态、滑块和和弦文字顺序合理 |
| 触控 | 主要目标至少 48dp |
| 字体 | 最大辅助字体下不截断核心内容 |
| 颜色 | 偏高/偏低/调准和完成状态不只靠颜色 |
| 动画 | 遵循减少动画；节拍视觉避免高频强闪烁 |
| 键盘 | Tab/方向/Enter/返回完成核心路径，无焦点陷阱 |
| 音频替代 | 节拍有视觉反馈，震动可选 |
| 和弦图 | 有完整、节流且可理解的文字描述 |

## 9. 性能预算

| 指标 | MVP 预算 |
|---|---|
| 冷启动 TTID | 中端机 P50 <= 1.5s，P95 <= 2.5s |
| 热启动 | P95 <= 1s |
| 调音反馈 | P95 <= 250ms |
| DSP | P95 小于一个 hop 周期 50% |
| 音频热路径 | 稳态接近零持续分配 |
| 曲谱滚动 | 无连续明显卡顿，慢帧低于 5% |
| 稳态内存 | 目标低于 200MB，无持续增长 |
| 音频资源 | 正常前台负载 AudioTrack underrun 为 0 |
| 包体 | 基础下载建议低于 80MB |
| 退出工具 | AudioRecord/AudioTrack 和线程及时释放 |

使用 Macrobenchmark、Baseline Profile、Memory Profiler、系统 Trace 和长时间运行测试验证，不能仅靠 Debug 主观观察。

## 12. 发布验收

- 无网络、无登录完成整个新手闭环。
- 原始麦克风音频不保存、不上传、不进入日志。
- Manifest 权限、导出组件、备份和网络安全配置通过审查。
- 内容、图片、声音、字体、曲谱和依赖许可齐全。
- 用户能清除练习历史、导入文件、缓存和全部数据。
- 发布版无敏感日志、调试端点和明文流量。
- 隐私政策、麦克风说明和实际行为一致。
