# XSTAR 调音器 HTML 原型

这是 Android 手机 App 的 HTML 交互原型。在 Chrome 或 Edge 中直接打开 [`tuner-prototype.html`](./tuner-prototype.html)，无需安装依赖或启动服务。手机中以全宽竖屏展示；电脑中展示居中的手机宽度画布，可使用浏览器设备模拟查看 360–440px 屏宽效果。

## 视觉方向

「舞台后台的精密仪器」：炭黑背景、荧光黄绿强调色、细线仪表、等宽参数，以及抽象琴头插画。音名是第一视觉焦点，偏差刻度是第二焦点，六弦选择是主要操作区。

- 偏低：向上箭头、文字建议、刻度左偏。
- 偏高：向下箭头、文字建议、刻度右偏。
- 调准：黄绿色、勾形符号和文字确认；容差为 ±3 音分。
- Android 竖屏单页：顶部应用栏、中央仪表、六弦选择、紧凑配置与进度、底部操作区。所有屏宽均使用手机布局。
- 固定单屏布局，不需要滚动；去掉顶部宣传文案，仪表区域随可用高度伸缩，小屏自动压缩辅助信息。底部模拟音准控件仅用于原型演示。
- 使用系统字体、内嵌 SVG 和原生 JavaScript，无外部资源依赖。

## 体验方式

1. 拖动底部「模拟音准」滑块，查看音名频率、指示线和操作建议。
2. 点击「一键调准」，自动模式会在 1.4 秒后选择下一根未完成的弦。
3. 点击任一琴弦可直接选择；手动模式调准后停留在当前琴弦。
4. 切换标准、Drop D 或 Open G 调弦，以及 432 / 440 / 442 Hz 标准音。
5. 点击「播放参考音」，播放当前琴弦的标准正弦波音，约两秒自动停止。
6. 支持暂停、继续、重置和右上角使用说明。

当前是视觉与交互原型，输入信号由滑块模拟，不采集麦克风。参考音通过浏览器 Web Audio 实际生成。

## 验证

已通过脚本语法和交互逻辑检查，覆盖音分反馈、目标频率换算、自动换弦、手动模式、调弦切换、标准音切换、暂停恢复、六弦完成和重置。实际视觉与音频效果请在浏览器中体验。
