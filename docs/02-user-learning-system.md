# 用户与学习体系设计

## 1. 目标

学习体系用于回答三个问题：

1. 用户目前具备哪些能力？
2. 为完成某首曲目还缺少哪些能力？
3. 下一次 5 至 20 分钟应该练什么？

系统以“能力”连接工具、知识、练习和曲谱，避免课程完成度成为唯一进度指标。

## 2. 用户阶段

| 阶段 | 用户状态 | 典型目标 | 产品重点 |
|---|---|---|---|
| L0 探索 | 刚拿到琴或尚未形成习惯 | 正确持琴、调准、弹响 | 极低门槛与即时反馈 |
| L1 起步 | 能弹少量开放和弦 | 稳定转换并完成第一首歌 | 单一路径、短练习 |
| L2 入门 | 能弹若干简单曲目 | 扩展和弦与节奏 | 曲目驱动与复习 |
| L3 进阶 | 有稳定练习习惯 | 横按、音阶、技巧、听力 | 专项训练和数据反馈 |
| L4 演奏 | 排练或演出导向 | 曲目、速度、编排和现场使用 | 曲谱、Setlist、脚踏控制 |
| L5 创作/教学 | 创作或教授他人 | 和声、编配、任务管理 | 高级理论与协作 |

MVP 完整覆盖 L0 至 L1，只为后续阶段定义模型和入口。

## 3. 能力模型

### 3.1 能力类别

| 类别 | 示例 |
|---|---|
| 设备与姿势 | 认识琴弦、正确持琴、拨片握法、基础保养 |
| 调音与听觉 | 标准调弦、判断高低、听辨稳定音高 |
| 左手 | 单音按弦、开放和弦、横按、击勾滑、推弦 |
| 右手 | 下扫、上下扫、分解、交替拨弦、闷音 |
| 节奏 | 拍号、四分、八分、十六分、切分、三连音、Swing |
| 指板 | 弦上音名、音程、把位连接、CAGED |
| 乐理 | 音程、音阶、和弦构成、调内和弦、功能和声 |
| 曲目应用 | 看和弦谱、分段、跟拍、完整演奏、移调 |
| 演奏管理 | 曲谱库、Setlist、设备音色、排练记录 |

### 3.2 掌握状态

每项能力使用以下状态：

| 状态 | 含义 |
|---|---|
| 未接触 | 用户尚未学习 |
| 已了解 | 完成知识内容，但未完成练习 |
| 练习中 | 完成至少一次练习，尚未达到建议标准 |
| 基本掌握 | 达到明确的 MVP 自评或量化标准 |
| 稳定掌握 | 多次在不同练习或曲目中达到标准；后续版本启用 |
| 待复习 | 超过复习间隔或近期表现下降 |

MVP 不把主观自评包装成精准自动评分。掌握依据应标明来自用户确认、练习次数、BPM 记录还是自动检测。

### 3.3 前置关系

能力关系使用有向无环图：

```text
认识六根弦
  -> 标准调弦
  -> 开始每次练习

正确按弦
  -> Em / Am / C / G / D
  -> 双和弦转换
  -> 四和弦循环

感受稳定拍
  -> 四分音符
  -> 八分扫弦
  -> 曲目节奏型

和弦循环 + 曲目节奏型
  -> 分段演奏
  -> 完整练习曲
```

系统允许用户绕过前置内容浏览和使用工具，但会明确显示推荐准备项。

## 4. MVP 新手路径

建议以 7 至 14 天完成为目标，每次 10 至 25 分钟。天数不是强制连续打卡。

| 序号 | 微课 | 最小知识 | 练习 | 完成标准 |
|---:|---|---|---|---|
| 1 | 认识你的吉他 | 琴头、品格、六根弦编号 | 找到指定琴弦 | 能按提示指出 1、3、6 弦 |
| 2 | 正确持琴与拨弦 | 坐姿、放松、拨弦位置 | 六根空弦逐根拨响 | 每根弦声音清楚，无需追求速度 |
| 3 | 第一次调音 | 音高偏低/偏高、调弦旋钮 | 标准六弦调音 | 六根弦均获得稳定“已调准”反馈 |
| 4 | 第一个和弦 Em | 品、手指编号、靠近品丝 | Em 按法与逐弦检查 | 用户确认六弦达到可接受发声 |
| 5 | 节拍基础 | 拍、BPM、4/4 | 60 BPM 四分下扫 | 连续完成 8 小节并自评稳定 |
| 6 | 学习 G 和弦 | 换指准备、减少多余动作 | Em-G 慢速转换 | 30 秒内完成目标次数，或按自定降级目标 |
| 7 | 学习 C 与 Am | 相似指形和锚点手指 | Am-C 转换 | 在无节拍和慢速节拍下完成循环 |
| 8 | 学习 D 和弦 | 局部扫弦和不弹弦 | G-D 转换 | 能避免明显误扫第六弦 |
| 9 | 四和弦循环 | 和弦进行和小节 | G-D-Em-C | 在建议起始 BPM 完成 8 轮 |
| 10 | 八分扫弦 | 下上扫、手臂连续运动 | 基础节奏型 | 在空弦与和弦上分别完成 |
| 11 | 第一首歌分段 | 段落、起拍、困难点 | 主歌/副歌分段 | 各段在降速或建议 BPM 完成 |
| 12 | 完整演奏 | 错误不中断、首尾结构 | 整曲演奏 | 用户完成整首并记录自评与目标 |

具体和弦和顺序需由吉他教学顾问基于首批合法练习曲复核。若歌曲仅需更少和弦，应进一步缩短首条路径。

## 5. 单课结构

每节课采用固定但可组合的步骤：

1. **目标**：一句话说明学完能做什么。
2. **准备**：琴、拨片、调音或建议 BPM。
3. **最小知识**：1 至 3 个概念，避免长篇教材。
4. **看与听**：图示、示范音频或短视频。
5. **跟做**：可交互步骤，必要时直接打开工具。
6. **练习**：明确时长、速度和成功条件。
7. **自检**：提供“我听到杂音”“手疼”“跟不上”等诊断入口。
8. **完成**：记录结果，只推荐一个下一步。

建议单课主体 3 至 8 分钟，练习可单独持续 5 至 15 分钟。

## 6. 练习类型

### 6.1 MVP 类型

| 类型 | 输入 | 过程 | 输出 |
|---|---|---|---|
| 调音检查 | 调弦预设 | 逐弦检测 | 完成弦数、总耗时 |
| 单和弦检查 | 和弦与文字指法 | 逐弦弹响、用户自检 | 问题类型、自评 |
| 和弦转换 | 2 至 4 个和弦、时长、BPM | 按提示循环 | 完成次数、最高稳定 BPM、自评 |
| 节奏跟拍 | 节奏型、BPM、小节数 | 节拍器和视觉提示 | 完成小节、BPM、自评 |
| 曲目分段 | 曲目段落、和弦、节奏 | 分段循环 | 完成状态、BPM、备注 |
| 整曲演奏 | 曲目结构 | 从头至尾演奏 | 完成、自评、下一目标 |

### 6.2 后续类型

- 指板找音与音程定位。
- 听辨音程、和弦性质和节奏。
- 技巧专项，包括击勾弦、滑音、推弦和闷音。
- 音频 A-B 循环、保持音高变速和伴奏练习。
- 基于单音检测的音准练习。
- 有可信基线后再评估完整和弦或节奏自动评分。

## 7. 难度与降级

每个练习提供推荐目标和可接受降级，防止新手因一次达不到标准而停止。

示例：

| 目标 | 推荐 | 降级 |
|---|---|---|
| Em-G 转换 | 60 BPM，每和弦 4 拍 | 无节拍、每 8 拍转换 |
| 四和弦循环 | 60 BPM，8 轮 | 45 BPM，4 轮 |
| 八分扫弦 | 连续 8 小节 | 空弦练习 4 小节 |

完成降级目标可以继续学习，但能力状态保持“练习中”，首页在合适时间建议复习。

## 8. 反馈与常见问题

反馈应该描述可操作行为，而不是只显示“错误”。

| 问题 | 建议反馈 |
|---|---|
| 按弦有杂音 | 指尖靠近品丝但不要压在品丝上；逐弦检查 |
| 手指疼 | 短暂休息；区分正常指尖不适与关节锐痛；不要强撑 |
| 转换太慢 | 先去掉节拍，观察共同手指和最远移动手指 |
| 跟不上节拍 | 降低 BPM 或只做下扫；保持不中断优先于快速 |
| 调音器跳动 | 单独拨一根弦、减小力度、靠近手机、静音其他琴弦 |
| 曲目太难 | 展示缺少的和弦与节奏，提供“准备后再练”和“仍然打开” |

健康提示应克制且清楚：持续关节疼痛、麻木或锐痛不是应坚持的练习反馈。

## 9. 曲目驱动学习

每首结构化曲目必须声明：

- 所需调弦、Capo、和弦和节奏型。
- 推荐与最低可练 BPM。
- 所需技巧与能力前置。
- 段落结构和各段难点。
- 可以跳转的知识和练习。
- 完成规则和下一首推荐依据。

用户选歌流程：

```text
选择曲目
  -> 查看“你已经会 / 建议先学”
  -> 直接打开或完成准备练习
  -> 分段练习
  -> 整曲演奏
  -> 更新能力证据与曲目状态
```

## 10. 复习与推荐

MVP 规则：

- 未完成会话优先于新内容。
- 新学和弦在下一次启动时提供一次短复习。
- 最近三次自评均为困难，建议降低 BPM 或回到前置练习。
- 曲目中标记困难的段落优先进入“今日 5 分钟”。
- 每次只给一个主要建议，允许用户浏览其他内容。

后续可使用间隔复习和表现趋势，但应保持推荐原因可解释。

## 11. 内容生产标准

- 每节课只有一个主要学习目标。
- 每个概念必须至少关联一个听觉或视觉示例和一个练习。
- 每项练习必须关联能力、难度、建议时长和完成条件。
- 每首曲目必须关联能力、和弦、节奏、来源和许可。
- 和弦图与文字指法必须由至少一名合格吉他手交叉校对。
- 节奏和曲谱必须在目标 BPM 实际演奏验证。
- 文案面向零基础，不以未解释术语解释另一个术语。
- 教学图片、音频和视频均需保存作者、来源和许可。

## 12. 后续学习路线

| 路线 | 前置 | 主要内容 | 应用目标 |
|---|---|---|---|
| 民谣弹唱 II | 完成第一首歌 | 更多开放和弦、分解、切分、Capo | 形成 5 首曲目库 |
| 横按突破 | 稳定开放和弦 | F/Bm、手型与省力方法 | 扩大可弹调性 |
| 指板与音阶 | 单音拨弦稳定 | 音名、音程、五声音阶、CAGED | 基础即兴 |
| 指弹入门 | 基础节拍稳定 | PIMA、分解、旋律与低音 | 完成一首指弹练习曲 |
| 电吉他入门 | 基础持琴与节拍 | Power Chord、闷音、Riff、效果链基础 | 完成一首 Riff 曲 |
| 乐队与演出 | 多首曲目经验 | Setlist、排练、调弦和音色切换 | 完成一场排练/演出 |
