# XSTAR 节拍器 · 移动端设计方案

## 1. 设计方向：PULSE / 掌心节奏仪

将节拍器做成一台克制的数字音乐设备：炭黑画布、荧光黄绿节奏环、大字号速度，以及清晰的逐拍指示。酷炫来自精确的仪表和随音乐发生的局部反馈，而不是满屏装饰与持续闪烁。

与现有调音器保持同一视觉语言。默认打开即为 120 BPM、4/4 拍、四分音符，点击一次开始练习。

**原型入口：[metronome-prototype.html](metronome-prototype.html)**。直接用 Chrome / Edge 打开，无依赖、可离线使用；桌面呈现手机宽度画布，手机使用全宽界面。

## 2. 首屏结构

```text
┌────────────────────────────┐
│ 声音    XSTAR / 节拍器  设置 │
│                      00:00 │
│                            │
│          节奏光环           │
│          120               │
│          BPM               │
│                            │
│ 40 ───────●────────── 240   │
│     60   90   120   160     │
│                            │
│ 节拍                  4/4  │
│   [1重] [2轻] [3轻] [4轻]   │
│                            │
│ [4/4 拍] [♩ 细分] [电子音]  │
│                            │
│   [ TAP ] [ ▶ 开始练习 ]    │
└────────────────────────────┘
```

### 信息优先级

1. **速度**：BPM 为第一视觉焦点，90–104sp 等宽数字；外围刻度让界面具有仪器感。
2. **拍位**：播放时高亮当前拍的数字与边框，并同步显示“第 N 拍”，不只靠颜色传达。
3. **行动**：底部荧光主按钮可切换开始 / 停止；Tap 为低权重轮廓按钮。
4. **配置**：拍号、细分、音色以三个紧凑入口呈现，点击打开底部面板。
5. **辅助**：右侧本次练习时长、左上角声音开关、右上角设置入口。不显示“准备就绪 / 正在练习”状态文案，播放状态由主按钮和拍位表达；底部不放宣传、操作提示文案或恢复默认入口。Tap 次数直接显示在 Tap 按钮内。

节奏环由低亮刻度、局部弧线和中心读数组成。每拍仅局部亮起，避免全屏闪烁；静止时也有完整视觉构图。遵循系统“减少动态效果”，并提供关闭节拍动画的选项。

## 4. 交互方案

### 速度

- 范围 40–240 BPM，初始 120。
- 去掉加减按钮，使用速度滑条调整（步进 1 BPM），四个常用速度用于快速定位。
- 点击中央 BPM 打开数字输入面板，可直接输入速度并验证范围。
- 播放中调速，下一个尚未排程的拍开始采用新速度，不重复启动计时器。
- Tap 连续点击至少两次计算 BPM；最近最多六个间隔取平均，超过两秒未点击重新开始。面板显示 Tap 次数与结果。

### 节拍与细分

- 拍号：2/4、3/4、4/4、5/4、6/8、7/8；切换拍号后从第一拍重新开始。
- 6/8、7/8 在本原型中按分母音符计拍，BPM 为八分音符速度；6/8 默认第 1、4 拍重音，7/8 默认第 1、3、5 拍重音（2+2+3）。拍号面板有明确说明。
- 逐拍点击循环“重音 → 轻音 → 静音 → 重音”，静音拍依然保持时间和视觉拍位。
- 细分：每拍一声、每拍两声、三连音、每拍四声；使用文字与节奏示意共同表达。
- 音色：电子、木块、柔和。声音关闭时仍可练习视觉节奏。

### 播放与状态

| 状态 | 页面反馈 |
|---|---|
| 待机 | 节奏环静止，按钮“开始练习” |
| 播放 | 当前拍和局部光环同步点亮，按钮“停止练习”，显示本次计时 |
| 无声播放 | 左上角声音图标显示关闭，按钮与拍位反馈正常 |
| 停止 | 拍位清空、计时保留；再次开始从第一拍计时 |
| 参数面板 | 从底部打开，关闭后回到原控制，播放不中断 |
| 切至后台 | HTML 原型停止播放，避免后台计时节流造成错拍 |
| 音频不可用 | 明确提示，切换至视觉练习，可在声音按钮重试 |

设置面板内提供“恢复默认设置”入口。点击后停止播放，重置速度、拍号、细分、音色、重音、音量、声音与动画开关，清空计时和 Tap 记录，不显示“已恢复默认设置”提示文案。设置和速度保存到本机；不恢复播放状态。

## 5. 移动端适配与可访问性

- 重点画布为 390 × 844，支持 320–440px 手机宽度；宽屏仍保持手机单栏。
- 较矮屏幕压缩节奏环与垂直间距，极小高度或大字体允许滚动，保证所有操作可达。
- 支持安全区；不模拟系统状态栏，不占用真实手机顶部空间。
- 输入、按钮有清晰键盘焦点；面板使用原生 dialog，支持 Escape、关闭按钮和点击遮罩关闭。
- 参数按钮提供完整无障碍标签；实时拍位不逐拍触发读屏播报，避免干扰。
- 运行状态、重音与静音均有文字，不仅依赖黄绿、橙色和灰色。

## 6. 原型能力与正式 Android 落地

原型可实际播放音频，支持速度调整、Tap、拍号、细分、逐拍重音、静音、音色、计时、设置面板与本地保存。使用 Web Audio 时间轴提前排程，视觉跟随音频时间，声音不依赖 CSS 动画或逐拍 setInterval。

Android 建议以 Jetpack Compose 实现页面与 ModalBottomSheet；界面状态由 ViewModel 管理。节拍声音由独立音频引擎在音频时钟上生成，Compose 动画只订阅拍位，不能驱动节拍。正式实现需验证设备音频延迟、快速调参、耳机与扬声器切换、音频焦点、锁屏策略。

首版聚焦可靠节拍。渐进加速、练习计划和历史统计可在后续扩展，避免占据首屏。

### Android 实现

原生页面位于 `app/src/main/kotlin/com/xstar/guitar/ui/MetronomeScreen.kt`，采样时钟音频引擎位于 `audio/AudioMetronome.kt`。已接通“今天 → 常用工具 → 节拍器”和“工具 → 节拍器”；返回手势或设置面板内“返回工具”可退出。配置本地保存，切至后台停止播放；首页无底部提示文案。Tap 次数在按钮内反馈，恢复默认仅在设置面板内提供。

已通过 Debug 构建、单元测试、Lint，以及 NX741J（Android 16）上的原生界面交互测试，覆盖 6/8 分组重音、逐拍切换、三连音、播放停止、声音开关、速度滑条及恢复默认。Debug APK 已安装到该手机，并检查了原生节拍器页面截图。

## 7. 评审步骤

1. 在手机尺寸打开原型，检查 BPM、逐拍指示与开始按钮的层级。
2. 开始播放并拖动速度；对比三种音色和四种细分。
3. 选择 6/8，检查第 1、4 拍重音；逐拍切换重 / 轻 / 静音。
4. 连续点击 Tap，停顿超过两秒后重新点击，检查测速重置。
5. 关闭声音和动画，检查视觉练习与减少动态效果。
6. 在 320 × 568、390 × 844 与 440 × 956 画布检查控制可达性。

### 本轮验证记录

已使用 Edge 浏览器自动化验证数字输入、速度加减、6/8 默认重音、逐拍重音切换、三连音配置、Web Audio 播放流程、计时、静音、停止、Tap 测速、本地保存和恢复默认；无脚本运行错误。三个手机尺寸均无横向溢出，390 × 844 下完整首屏可见，320 × 568 下允许纵向滚动。已检查 390 × 844 截图；音色听感和实际设备音频延迟需真机试听评审。
