# Android 调音器 · 六弦光轨定稿

直接打开 [tuner-concepts.html](./tuner-concepts.html)。已选用 C 六弦光轨方案，移除顶部方案切换及底部模拟音准控件。手机竖屏单屏布局，电脑端也保持手机画布。

| 方案 | 视觉 | 音准反馈 |
|---|---|---|
| A 极简霓虹 | 黑绿、超大音名、荧光六弦按钮 | 横向光标，调准时音名亮起 |
| B 星环仪表 | 深蓝与冰蓝、细线圆环、圆形选弦 | 环形光点左右偏转，调准时圆环亮起 |
| C 六弦光轨 | 暖黑与橙色、六条纵向琴弦 | 当前弦光点上下移动，偏低向上调、偏高向下调 |
| D 专业极简 | 石墨灰与薄荷绿、轻字重、纯文字选弦 | 细横线与小圆点，调准时音名变绿 |

支持选弦、自动／手动模式、标准／Drop D／Open G 调弦、标准音设置与实际参考音播放。音准读数为示例，不采集麦克风；参考音播放不计入调准进度。

## 动效

- 选弦：当前光轨短暂轻颤后稳定。
- 常态：沿弦缓慢流光，音准光点柔和呼吸。
- 参考音播放：弦线细微振动，流光加速，音名增加柔光；停止后恢复。
- 系统开启减少动画时关闭动效。

音名叠加在六弦光轨上，位于仪表区域上方 7% 处，大音名使用 40% 不透明度，避开中央音准光点。主界面移除 Hz 读数、偏高／偏低文字、音分读数及操作提示，仅保留弦号与音名。

标准调弦选项移至顶部左侧，自动识别保持居中，移除独立参考音图标。点击光轨或底部音名会选择该弦并播放约两秒标准音，再次点击可重播。快速切换琴弦时取消上一次播放请求。

右上角设置按钮打开设置弹窗，主页面不滚动。
