# XStar Guitar 吉他学习与练习功能需求文档

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 文档状态 | 功能基线 / 需求草案 |
| 适用产品 | XStar Guitar |
| 首发平台 | Android |
| 首发方向 | 民谣吉他弹唱，同时为指弹、电吉他、乐理与创作预留能力模型 |
| 目标用户 | 零基础、入门、进阶、演奏与创作用户 |
| 核心目标 | 让用户按技能分类选择练习，获得正确指导，逐步达到可演奏、可理解、可应用的能力 |

本文定义完整的吉他学习与练习内容体系。它不规定具体开发排期，而规定产品应该覆盖什么、每类练习如何设计、内容需要达到什么质量，以及练习如何与课程、工具、曲谱和用户进度关联。

## 2. 产品定位

### 2.1 核心承诺

XStar Guitar 应让用户能够：

1. 找到自己想练的具体技能。
2. 知道这个技能解决什么问题。
3. 看懂正确动作、声音和练习方法。
4. 用可控难度重复练习。
5. 知道自己是否完成了本次目标。
6. 将技能应用到和弦、节奏、曲目、即兴或创作中。

### 2.2 产品结构

练习不是孤立的计时器，而是连接四类内容的中心：

```text
工具：调音器、节拍器、和弦库、音阶和音色工具
  ↓
知识：音乐基础、吉他构造、指法、节奏、和声
  ↓
练习：动作、听觉、节奏、技巧和综合训练
  ↓
应用：曲谱、歌曲、伴奏、即兴、创作和演奏记录
```

用户可以从任意一层进入，但每个练习都应尽量提供“为什么练”和“练完用在哪里”。

### 2.3 设计原则

- 按能力分类，而不是把所有内容强行放入一条课程线。
- 每个练习只设置一个主要目标。
- 先保证正确动作和正确声音，再追求速度。
- 先练分解动作，再练组合动作，最后进入音乐情境。
- 练习必须同时覆盖视觉、听觉、动作和理解四种反馈。
- 难度独立于用户总等级；用户可以在不同分类拥有不同水平。
- 不把一次完成记录直接等同于掌握。
- 在没有可靠识别能力时，不伪装成自动评分。
- 高级内容可以开放浏览，但应清楚显示必要前置能力。
- 音乐健康、手部放松和避免疼痛属于基础指导，不是附加提示。

## 3. 学习能力总地图

一级分类按训练能力组织，分类内部使用“入门、基础、进阶、高级”四级难度。难度表示内容复杂度，不表示用户价值或绝对等级。

### 3.1 能力分类总表

| 分类 | 主要解决的问题 | 代表内容 |
|---|---|---|
| 吉他基础与演奏准备 | 能否正确认识、持握和准备乐器 | 琴弦、品位、持琴、拨片、调弦、保养 |
| 左手基础 | 能否清楚按弦、移动和控制手指 | 单音、爬格子、独立性、换把、消音 |
| 右手基础 | 能否稳定拨弦和控制触弦 | 拇指、手指、交替拨弦、PIMA、拨片 |
| 单和弦 | 能否形成清楚、稳定的和弦声音 | 开放和弦、封闭和弦、和弦图、发声检查 |
| 和弦转换 | 能否在音乐时间内从一个和弦移动到另一个和弦 | 双和弦、和弦进行、共同手指、无停拍转换 |
| 节奏与拍感 | 能否感受拍子并稳定演奏 | 拍号、细分、休止、切分、三连音、Swing |
| 分解与指弹 | 能否同时处理低音、伴奏和旋律 | 分解和弦、PIMA、固定低音、独立声部 |
| 扫弦与拨片 | 能否控制扫弦方向、力度和音色 | 下扫、上下扫、重音、闷音、拨片控制 |
| 拍弦与打板 | 能否把打击性声音融入节奏 | 拍弦、闷音、身体打板、扫弦结合 |
| 听音与听力 | 能否听出音高、节奏、和弦和音乐关系 | 高低音、音程、和弦性质、调性、扒谱 |
| 乐理与读谱 | 能否理解音乐结构并读懂材料 | 音名、音程、调式、和弦构成、六线谱、节奏谱 |
| 音阶与指板 | 能否在指板上找到音并组织旋律 | 音名、五声音阶、大调音阶、CAGED、把位 |
| 吉他技巧 | 能否控制装饰、延音和特殊音色 | 击弦、勾弦、滑音、推弦、揉弦、泛音、闷音 |
| 综合演奏 | 能否把技能连续应用到音乐中 | 曲目片段、伴奏、独奏、排练、完整演奏 |
| 即兴与创作 | 能否从理解音乐到主动表达 | 句子、问答、和弦进行、编配、作曲、录音 |
| 演奏管理 | 能否长期练习、排练和准备演出 | 计划、复盘、Setlist、设备、舞台准备 |

### 3.2 用户能力状态

每项能力使用以下状态：

| 状态 | 含义 |
|---|---|
| 未接触 | 用户尚未学习或练习 |
| 已了解 | 看过指导或完成知识内容，但未形成动作证据 |
| 练习中 | 已完成至少一次练习，仍需要重复 |
| 基本掌握 | 达到该练习的最低目标，能够在受控条件下完成 |
| 稳定掌握 | 多次、不同速度或不同音乐情境下完成 |
| 待复习 | 一段时间未练，或近期自评和表现下降 |

能力状态必须标明依据，例如“用户自评”“完成次数”“最高稳定 BPM”“听力答题正确率”或“教师标记”。系统不应把没有可靠检测依据的结果描述为客观演奏评分。

## 4. 完整学习内容体系

以下内容是产品长期内容基线。每个小节都可以拆为知识卡、示范、专项练习和曲目应用。

## 4.1 吉他基础与演奏准备

### 入门

- 吉他各部位：琴头、琴颈、品丝、品位、琴桥、音孔、弦钮。
- 六根弦的编号、名称和标准音：E、A、D、G、B、E。
- 品位、弦、空弦和按弦的概念。
- 坐姿、站姿、琴体支撑和肩颈放松。
- 左手拇指位置、手腕角度和手指触弦位置。
- 右手拨弦位置、手腕放松和手指运动方向。
- 拨片握法、拨片角度和拨片露出长度。
- 标准调弦和调音器使用。
- 基本护弦、换弦、清洁和收纳。

### 基础

- 不同拨弦位置的音色变化。
- 不同力度与触弦角度。
- 练习前的调音、姿势和手部检查。
- 常见琴弦、品丝和弦高问题的识别。
- 练习时间、休息和疼痛边界。

### 进阶与高级

- 不同吉他类型的结构和音色差异。
- 弦距、弦径、变调夹和调弦选择。
- 现场换弦、备用琴和基础设备管理。
- 电吉他信号链、音箱、效果器和基础增益控制。

### 对应练习

- 找弦、找品、报音名。
- 六根空弦逐根弹响。
- 调音流程模拟和实际调音。
- 放松检查与无琴手指运动。
- 正确持琴 5 分钟自检。

---

## 4.2 左手基础

### 入门

- 单指按弦和清楚发声。
- 指尖靠近品丝但不压在品丝上。
- 单弦单音、相邻品位和简单旋律。
- 1-2-3-4 爬格子。
- 手指编号和最小移动。
- 按弦、释放、静音三种动作。

### 基础

- 1-2-3-4、1-3-2-4 等手指排列。
- 跨弦移动和跳弦。
- 手指独立性与抬指高度控制。
- 保留指和锚点手指。
- 左手消音和右手消音的区别。
- 同一旋律在不同把位演奏。

### 进阶

- 换把和位置移动。
- 伸展、收缩和横向移动。
- 多声部中保持低音或旋律。
- 左手节奏与右手节奏的独立。
- 速度训练中的放松、准确和经济动作。

### 高级

- 高速音阶和连续换把。
- 不规则指法和跨弦句型。
- 多声部独立控制。
- 无视觉依赖的指板定位。

### 对应练习

- 单音清晰度检查。
- 爬格子节拍练习。
- 指法排列随机练习。
- 保留指转换练习。
- 指板定位练习。
- 左手消音与右手消音对比练习。

---

## 4.3 右手基础

### 入门

- 拇指拨低音弦。
- 食指、中指、无名指拨高音弦。
- 单弦交替拨弦。
- 相邻弦和跳弦。
- 手指回位和运动幅度。
- 拨片交替拨弦。

### 基础

- PIMA 指法。
- P-I-M-A、P-M-I-A、P-I-M-I 等常用模式。
- 低音与高音交替。
- 空弦分解和弦。
- 拨片上下交替。
- 跨弦拨片经济动作。

### 进阶

- 分解和弦中的重音与旋律突出。
- 低音固定、高音变化。
- 指弹中的拇指独立。
- 混合拨弦。
- 交替拨弦速度和准确度。

### 高级

- 多声部指弹。
- 旋律、低音和内声部独立。
- Tremolo、轮指和快速重复拨弦。
- 复杂跨弦和不规则分组。

### 对应练习

- 空弦拨弦模式。
- 节拍器下单弦交替拨弦。
- PIMA 分解循环。
- 低音加旋律练习。
- 固定低音伴奏练习。

## 4.4 单和弦与和弦知识

### 入门开放和弦

建议首批覆盖：Em、Am、C、G、D、E、A、Dm。

每个和弦必须提供：

- 和弦名称、根音和构成音。
- 和弦图、弦线、品位、手指编号。
- 空弦、不弹弦和需要消音的弦。
- 文字版按法，支持 TalkBack。
- 逐弦发声示范。
- 常见杂音原因。
- 简化指法与替代指法。
- 使用该和弦的曲目和转换练习。

### 基础

- 大三和弦、小三和弦和属七和弦的听感。
- 开放和弦的根音位置。
- 和弦按法与手指移动。
- 和弦琶音和逐弦检查。
- 和弦转换前的预备手型。

### 进阶

- 七和弦、挂留和弦、加音和弦。
- 封闭和弦和横按基础。
- F、Bm 等常见横按。
- 同一和弦的不同把位。
- 转位和低音变化。
- 和弦功能与调内和弦。

### 高级

- 高级和弦色彩：maj7、m7、9、11、13、sus、add9。
- 和弦替代、三全音替代和经过和弦。
- 根音省略和声部配置。
- 爵士常用按法与声部连接。

### 对应练习

- 单和弦按下、释放和重复。
- 逐弦发声检查。
- 两种指法比较。
- 和弦组成音识别。
- 同一和弦不同把位寻找。

## 4.5 和弦转换

### 入门

- Em-Am、C-Am、G-D、Em-G、D-A。
- 无节拍手型转换。
- 每次转换前的预备手型。
- 共同手指和最远移动手指。

### 基础

- 每 4 拍转换。
- 60 BPM 下双和弦循环。
- 30 秒转换次数。
- G-C-D、G-D-Em-C 等常见进行。
- 和弦转换与四分下扫结合。

### 进阶

- 每 2 拍转换。
- 八分扫弦中的不停拍转换。
- 开放和弦与横按转换。
- 复杂和弦进行和预判。
- 变调夹下的和弦进行。

### 高级

- 快速和声进行。
- 爵士和弦声部连接。
- 和弦替代与即时转调。
- 伴奏中根据歌手音域即时移调。

### 对应练习

- 无节拍手型切换。
- 计时转换。
- 节拍器循环。
- 不中断转换。
- 和弦进行听觉记忆。
- 曲目困难段落循环。

## 4.6 节奏、拍感与节拍器

### 入门

- 拍、拍号、小节和速度。
- 4/4 拍中的第一拍重音。
- 四分音符、二分音符、全音符。
- 八分音符和“1 & 2 &”。
- 预备拍和跟拍。
- 空弦跟拍。

### 基础

- 八分上下扫。
- 休止和停顿。
- 重音位置。
- 基础切分。
- 十六分细分。
- 2/4、3/4、6/8 拍。

### 进阶

- 三连音。
- Swing 和直拍。
- 复杂切分和弱起。
- 节拍器静音小节。
- 变速和渐快渐慢。
- 复合拍与多层节奏。

### 高级

- 不对称拍号。
- 节奏错位、跨小节重音。
- 多拍号切换。
- Polyrhythm 基础。
- 自由速度与严格速度的切换。

### 对应练习

- 拍手与数拍。
- 空弦跟拍。
- 单和弦节奏型。
- 只听节拍器内拍。
- 关闭部分小节声音后保持拍感。
- 同一节奏型逐步提速。

## 4.7 扫弦与拨片

### 入门

- 拨片握法和角度。
- 下扫动作。
- 上扫动作。
- 手腕放松和小幅度运动。
- 空弦扫弦。
- 四分音符下扫。

### 基础

- 八分音符上下扫。
- 连续摆动手腕。
- 弱拍上扫。
- 扫弦幅度和触弦数量。
- 下扫重音。
- 和弦转换与扫弦结合。

### 进阶

- 常见民谣扫弦型。
- 休止扫弦。
- 闷音扫弦。
- 切分扫弦。
- 重音移动。
- 不同力度的段落表达。

### 高级

- 快速复杂扫弦。
- 拨片与手指混合。
- 扫弦伴奏中的旋律突出。
- Funk、Reggae、摇滚等风格型节奏。
- 扫弦音色、动态与编配控制。

### 对应练习

- 方向识别。
- 空弦节奏轨道。
- 单和弦节奏轨道。
- 扫弦型分层练习：节拍、方向、和弦、重音。
- 曲目节奏型循环。

### 入门

- 基础 PIMA。
- 低音加高音交替。
- 简单四拍分解。
- 和弦内逐音拨奏。

### 基础

- 常见分解节奏。
- 固定低音。
- 低音、内声部和高音顺序。
- 分解和弦与和弦转换。
- 右手模式记忆。

### 进阶

- 旋律与伴奏同时演奏。
- 拇指独立低音。
- 预备音、延音和连奏。
- 指弹中的跨弦跳跃。
- 分解与歌词演唱协调。

### 高级

- 独立编配指弹曲。
- 多声部独立。
- 复杂旋律、低音和内声部。
- Percussive fingerstyle。
- 轮指、泛音和扩展技巧结合。

### 对应练习

- 空弦分解。
- 和弦分解模式。
- 固定低音练习。
- 旋律加和弦练习。
- 指弹段落循环。

### 入门

- 右手闷音。
- 空弦拍弦动作。
- 拍弦与下扫的时机。
- 拍弦声音与正常音的区别。

### 基础

- 下扫-上扫-拍弦组合。
- 闷音扫弦。
- 拍弦重音。
- 拍弦与和弦转换。

### 对应练习

## 4.10 听音与听力训练

### 入门

- 高音、低音和相同音。
- 音长和音量的区别。
- 听辨单音。
- 听辨节奏快慢。
- 听辨拍数和重音。

### 基础

- 大调与小调听感。
- 大三和弦与小三和弦。
- 根音和低音辨识。
- 上行、下行和重复旋律。
- 常见节奏型听辨。

### 进阶

- 音程听辨：二度至八度。
- 和弦质量：maj、min、7、sus。
- 常见和弦进行。
- 调性中心判断。
- 旋律跟唱和在琴上寻找。
- 节奏听写。

### 高级

- 复杂和弦色彩。
- 转调和离调听辨。
- 和声功能听辨。
- 即兴句子的听写。
- 完整扒谱：节奏、和弦、低音、旋律。

### 对应练习模式

- 选择题。
- A/B 比较。
- 听后在指板选择答案。
- 听后模唱或弹奏。
- 节奏复现。
- 听写和弦进行。

听音练习首版可以采用本地音频题目和用户选择，不依赖麦克风。要求用户弹奏答案时，再单独申请音频权限并明确说明用途。

## 4.11 乐理与读谱

## 5. 练习内容的统一结构

每个练习内容必须采用统一元数据和内容结构，以便不同分类复用同一套界面。

### 5.1 练习元数据

| 字段 | 说明 |
|---|---|
| `id` | 稳定唯一 ID，不随标题变化 |
| `category` | 能力分类 |
| `level` | 入门、基础、进阶、高级 |
| `title` | 练习名称 |
| `objective` | 一句话目标 |
| `estimatedMinutes` | 预计练习时长 |
| `requiredTools` | 调音器、节拍器、曲谱等 |
| `requiredSkills` | 前置能力 |
| `targetSkills` | 本练习训练的能力 |
| `difficulty` | 内容难度 |
| `recommendedBpm` | 推荐速度，可为空 |
| `minimumBpm` | 可接受最低速度，可为空 |
| `completionRule` | 完成条件 |
| `degradationRule` | 降级练习规则 |
| `relatedContent` | 相关知识、和弦、曲目和练习 |
| `contentVersion` | 内容版本 |

### 5.2 练习正文结构

1. **目标**：明确用户本次应该获得什么能力。
2. **适用场景**：说明这个能力在歌曲、伴奏或演奏中的用途。
3. **准备**：调音、姿势、拨片、节拍器和设备。
4. **最小知识**：只解释完成本练习所需的概念。
5. **动作指导**：手指、手腕、拨片、触弦和放松要求。
6. **听觉目标**：用户应该听到什么正确声音。
7. **示范**：正常速度、慢速和必要的错误示范。
8. **分步练习**：从最简单版本逐步增加条件。
9. **正式练习**：计时、节拍器、循环、题目或曲谱片段。
10. **自检**：用户可以判断清晰度、稳定度、舒适度和困难点。
11. **完成条件**：明确什么情况下可以结束。
12. **常见问题**：给出可执行的修正动作。
13. **下一步**：只推荐一个最相关的后续练习。

### 5.3 指导内容的质量要求

- 不使用“放松一点”“注意节奏”等无法执行的空泛描述。
- 每条指导都尽量包含动作、位置、时间或声音结果。
- 动作说明必须与示范音频、图片和谱面一致。
- 对左手、右手、拨片、节拍和声音分别说明。
- 新术语首次出现时提供短解释。
- 必须区分“正常不熟练”“需要降速”和“可能造成伤害的疼痛”。
- 指导中不得鼓励持续忍受关节锐痛、麻木或刺痛。

## 6. 练习模式

不同技能使用不同执行模式，但共享准备、会话、暂停、结果和历史框架。

### 6.1 指导型练习

适合单和弦、姿势、拨片、技巧拆解。

功能：

- 分步图文指导。
- 示范播放。
- 慢速重复。
- 用户确认当前动作。
- 逐项自检。
- 完成后记录用户确认结果。

### 6.2 节拍器型练习

适合和弦转换、节奏、扫弦、分解和技巧速度训练。

功能：

- BPM 设置。
- 预备拍。
- 拍号和细分。
- 当前拍视觉提示。
- 节奏动作显示。
- 循环次数或练习时长。
- 降速、重来和自动递增的扩展能力。

### 6.3 曲谱跟练型

适合曲目分段、指弹谱、扫弦谱和完整演奏。

功能：

- 选择段落或小节范围。
- 播放示范。
- 速度调整。
- 循环播放。
- 自动跟随。
- 当前和弦、简谱、歌词和六线谱高亮。
- 练习段落完成记录。

### 6.4 听辨题型练习

适合音高、音程、和弦性质、节奏和调性训练。

功能：

- 本地播放题目。
- 选择题、按钮题或指板点选。
- 答案解释。
- 错题重复。
- 正确率和题目难度记录。
- 不默认申请麦克风权限。

### 6.5 模仿型练习

适合节奏、旋律、听写和即兴。

流程：

```text
播放示范 → 用户模仿 → 自评或受控检测 → 对比 → 再练一次
```

自动检测必须明确检测范围。例如只检测单音音高，不宣称可以准确识别完整和弦、复杂扫弦或整段演奏。

### 6.6 创作型练习

适合和弦进行、旋律、即兴和编配。

功能：

- 提供限制条件，例如调性、拍号、和弦进行。
- 提供伴奏循环。
- 记录用户选择的和弦、音阶或节奏。
- 支持文字备注和短录音的后续扩展。
- 重点评价完成和表达，不只评价技术准确度。

## 7. 练习会话功能需求

### 7.1 练习准备页

必须展示：

- 练习名称和目标。
- 练习预计时长。
- 推荐 BPM 或题目数量。
- 需要的工具和准备动作。
- 完成条件。
- 达不到目标时的降级方案。
- 前置能力和相关内容。

主按钮使用具体动词，例如“开始四分下扫”，而不是“开始”。

### 7.2 练习中页面

必须优先显示当前动作，避免统计信息喧宾夺主。

通用元素：

- 当前目标。
- 当前步骤或当前和弦。
- 下一步提示。
- 当前拍、BPM 或题号。
- 进度。
- 暂停。
- 重新开始。
- 降低难度或速度。

练习会话中应支持屏幕常亮设置，但不能强制永久常亮。

### 7.3 暂停、退出和恢复

状态：

```text
NOT_STARTED
→ RUNNING
→ PAUSED
→ COMPLETED
→ ABANDONED
→ INTERRUPTED
```

规则：

- 暂停不算完成。
- 主动退出时允许保存为未完成。
- 强制停止、进程终止或音频中断后恢复为未完成或中断。
- 未达到最短有效练习时长的会话可以只记录为尝试，不计入掌握证据。
- 恢复会话时显示上次步骤、速度和已完成进度。

### 7.4 结果页

结果页必须回答：

1. 本次练了什么。
2. 实际完成了多少。
3. 是否达到本次目标。
4. 用户自评如何。
5. 下一次应该做什么。

结果数据可以包括：

- 实际时长。
- BPM。
- 完成轮数、小节数或题目数。
- 正确率或用户自评。
- 失败或困难原因。
- 是否使用降级目标。
- 关联能力证据。

不应在没有可靠依据时显示“准确率 93%”“演奏质量 87 分”等伪精确指标。

### 7.5 自评和问题标记

用户可以快速选择：

- 很顺畅。
- 基本完成，但有停顿。
- 节奏不稳。
- 有杂音。
- 手指跟不上。
- 听不清目标。
- 手部不舒服。
- 需要降低速度。
- 不理解动作。

这些标记用于下一次推荐和内容质量分析，不直接作为惩罚或排名。

## 9. 课程、练习和曲目关系

### 9.1 从课程进入练习

课程可以调用任意分类中的练习：

```text
课程：学习 G 和弦
  → 和弦详情
  → 单和弦发声练习
  → Em-G 转换练习
  → 进入歌曲中的 G 和弦段落
```

课程完成不等于练习掌握。课程可以记录“已完成练习”，能力状态根据证据单独计算。

### 9.2 从曲目进入练习

曲目必须声明：

- 调弦和 Capo。
- 所需和弦。
- 所需节奏型。
- 所需技巧。
- 推荐 BPM 和最低可练 BPM。
- 段落及其难点。
- 关联练习。

用户点击曲谱中的和弦、节奏或技巧时，应进入对应详情，并支持返回到原小节和滚动位置。

### 9.3 从练习进入曲目

每个技能练习可以关联应用内容，例如：

- 学完八分上下扫：练习某首歌的主歌。
- 学完 G-D-Em-C：练习四和弦歌曲。
- 学完拍弦：练习某首歌的副歌节奏。
- 学完五声音阶：进入伴奏即兴。

## 10. 推荐与复习规则

推荐系统首版使用可解释规则：

1. 优先恢复未完成会话。
2. 优先复习用户标记困难的内容。
3. 最近三次都选择“困难”时，推荐前置练习或降低难度。
4. 新学和弦在后续练习中安排单和弦复习。
5. 某技能达到基本掌握后，推荐关联曲目，而不是继续堆同类题目。
6. 长时间未练的能力标记待复习。
7. 每次只突出一个主要推荐。

推荐文案必须说明原因，例如：

> 你上次在 60 BPM 的八分扫弦中出现停顿，今天建议用 50 BPM 再练 5 分钟。

## 11. 数据模型需求

练习内容应复用项目已有的 `SkillEntity`、`ExerciseEntity`、`PracticeSessionEntity` 和 `SkillEvidenceEntity` 设计，并补充以下字段或关系。

### 11.1 Exercise

```kotlin
data class Exercise(
    val id: String,
    val category: PracticeCategory,
    val level: PracticeLevel,
    val title: String,
    val objective: String,
    val mode: PracticeMode,
    val estimatedMinutes: Int?,
```

### 11.2 关联关系

- `ExerciseSkill`：练习与目标能力。

- `ExerciseChord`：练习涉及的和弦。
- `ExerciseRhythm`：练习涉及的节奏型。
- `ExerciseSong`：练习关联曲目。
- `ExerciseMedia`：示范图片、音频、视频和动画。
- `ExerciseStep`：分步指导。
- `ExerciseVariant`：同一练习的降速、简化和进阶版本。

### 11.3 PracticeSession

记录：

- 练习 ID。
- 开始和结束时间。
- 会话状态。
- 实际时长。
- 目标和实际 BPM。
- 完成轮数、小节数、题目数或正确率。
- 使用的降级版本。
- 用户自评。
- 问题标签。
- 备注。
- 关联曲目和段落。

### 11.4 SkillEvidence

能力证据来源包括：

- 用户完成练习。
- 用户自评。
- 听辨答题结果。
- BPM 和连续轮数。
- 曲目段落完成。
- 教师或用户手动标记。
- 受控音频检测结果。

不同来源必须保留，不应简单覆盖成一个无法解释的分数。

## 12. 自动检测边界

### 首版可以支持

- 调音器的单音音高检测。
- 本地播放和答题式听音训练。
- 节拍器视觉和音频同步。
- 曲谱播放位置、高亮和速度控制。
- 用户主动自评和练习数据记录。

### 需要验证后支持

- 单音是否在目标音高附近。
- 简单节奏是否与节拍接近。
- 单一练习动作的受控检测。

### 不应在没有可靠基线时承诺

- 完整和弦自动识别。
- 复杂扫弦方向准确识别。
- 拍弦和打板质量自动评分。
- 完整歌曲演奏质量评分。
- “弹得好不好”的综合客观分数。

所有麦克风功能必须遵守项目隐私基线：用户主动触发、权限前说明、本地实时分析、默认不保存、不上传，离开页面立即停止采集。

## 13. 内容生产与校验要求

### 13.1 每个练习发布前必须具备

- 稳定 ID。
- 分类、难度和目标能力。
- 明确前置条件。
- 正确示范或可验证的文字指导。
- 完成条件和降级条件。
- 至少一个常见问题及修正建议。
- 相关曲目或应用场景，若适用。
- 作者、来源和许可信息。

### 13.2 音乐内容校验

- 和弦图、指法文字和示范音一致。
- 节奏谱、动作箭头和示范音一致。
- 音阶音名、品位和调性正确。
- 听音题答案经过人工复核。
- 技巧说明符合实际演奏动作。
- 曲谱在标注 BPM 下可实际演奏。
- 难度升级没有不合理跳跃。
- 中文术语统一，首次出现时有解释。

### 13.3 内容安全与教学质量

- 不鼓励在疼痛、麻木或关节不适时继续练习。
- 不用羞辱、排名或连续打卡制造压力。
- 对儿童或新手内容使用明确、短句和动作化语言。
- 图片、音频、视频和曲谱均有许可证据。
- 未验证的技巧不能以“标准姿势”发布。

## 15. 验收标准

### 15.1 浏览与发现

- 用户可以从练习入口看到全部能力分类。
- 用户能区分左手、右手、和弦、节奏、听音、技巧和综合应用。
- 用户不需要先完成课程即可浏览和开始允许自由练习的内容。
- 每个练习都能看出难度、目标和预计时间。

### 15.2 指导与练习

- 新用户可以理解练习要做什么。
- 用户可以在开始前知道完成条件。
- 用户跟随指导可以完成至少一个最小练习循环。
- 节拍器型练习的视觉拍点和声音拍点一致。
- 练习被暂停、退出或杀进程后不会错误显示为完成。

### 15.3 音乐正确性

- 和弦图、指法、示范音和曲谱一致。
- 节奏型标注与示范一致。
- 音阶、音名、品位和调性经过人工校验。
- 听音题答案和解析经过复核。
- 高级技巧的动作和音频示范由具备演奏能力的内容人员审核。

### 15.4 长期学习

- 练习记录可以关联技能和曲目。
- 用户可以查看最近练习和待复习内容。
- 推荐内容能说明推荐原因。
- 完成一次练习不会直接伪装成“已经掌握”。
- 内容更新、标题变化和排序变化不会使历史进度丢失。

### 15.5 离线、无障碍和隐私

- 内置练习、示范和结果记录在离线状态下可用。
- 核心练习支持最大字体、深色模式和 TalkBack。
- 麦克风权限只在确有需要的练习中申请。
- 麦克风用途、保存策略和处理位置在授权前清楚说明。
- 不在日志中写入原始音频、用户文件名或完整曲谱正文。

## 17. 产品边界

本功能体系覆盖完整的吉他学习内容，但不代表首个版本同时实现所有内容。以下内容可以在内容模型中定义、在界面中展示路线，但需要后续具备足够内容和技术验证后开放：

- 完整和弦自动识别。
- 复杂节奏和扫弦自动评分。
- 高级音频质量评分。
- 专业效果器和音箱模拟。
- 多轨录音、混音和发布。
- 教师、学生和社交协作。
- 自动生成完整编曲。

功能范围可以逐步扩展，但分类、能力 ID、练习结构和曲目关联应保持稳定，以免后续内容无法迁移。
